## 产品行为

左侧继续是专题看板，右侧保留独立任务／项目聊天。聊天顶部进展卡提供方案、成果、验证、记录页签；每轮有独立 ID、阶段、结构化报告和实际工具记录，历史轮次可查看。项目未选任务时展示按实际任务状态计算的概览。AI 自述成果与实际命令依据分开标记，不能由 AI 报告把任务或 Git 标记为验收完成。仅用户确认当前结束的轮次可使卡片进入执行完成；合并仍单独审核。

pi 使用原独立会话，在正常请求内按约定的末尾 `<kaiwu-report>` JSON 块上报摘要／计划／成果／验证／阻塞／下一步／需确认问题，不增加总结模型调用。Go 严格验证大小、字段和引用后保存；原文保留，格式无效回退完整原文，长回复可展开。增量阶段仅在完整合法块到达后更新，不猜测未完成 JSON。已确认方案和关键问题可见，过程说明默认折叠。

## 通信与生命周期

新增 `/api/socket`，鉴权／Origin／Cookie 沿用现有服务。页面资源、登录／退出、首次认证快照与异常断线的轻量会话检查保留 HTTP；登录后的命令、模型查询、Git 预检／确认／回执、状态同步均经双向 WebSocket。兼容旧 HTTP 和 `/api/events` 客户端，正式页面不再用 revision 通知后 HTTP 全量刷新。

请求有 transport id，业务写入继续用现有 operationId 幂等。回复与事件独立关联；事件含连续 revision 和服务实例标识。首次推送快照，后续推送字段级增量；有限内存事件窗口内按 revision 补发，超出窗口或服务重启发权威快照，超过 256 KiB 按 UTF-8 安全边界分块，接收完整后原子替换。连接失效的迟到帧不更新新身份／范围，断线不自动重发副作用操作，而是查询原回执。

服务端通过当前项目的可见订阅每 3 秒触发有界 Git 检查；隐藏／切项目／断开停止对应订阅。已登记 Agent／Git 操作仍由服务生命周期持有，不受 WebSocket 关闭影响。消息读取 64 KiB 上限，慢消费者超时断开后可恢复；请求处理串行且有界，Store 锁不等待网络。
