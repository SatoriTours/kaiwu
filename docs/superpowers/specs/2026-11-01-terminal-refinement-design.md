## 目标与已确认交互

- 点击终端视图：没有终端时默认打开一个，有原终端则接回；不是进入网站就无条件启动 Shell。
- 支持多个终端的展示与切换；切换不停止其他终端、不重发输入。
- 同浏览器关闭网页再打开，接回上次工作区、终端列表与所选终端。Shell 原目录、运行命令和已有输出由原服务器进程保留。
- 上述恢复以服务持续运行为前提；不声称服务重启后可以恢复原 Shell。现有输出有界保留和截断提示仍须保留，不保证任意全屏应用像素级复原。
- 手动结束需确认；结束后不自动重开。没有新用户意图，不重放历史命令。

## 最终视觉：V7 A

- 终端工作区选择、标签、新建和更多操作并入全站 **48px 顶栏**，只在终端页面显示。取消独立终端工具栏及底部常驻说明条。
- 正文紧接顶栏，四周零边距，无嵌套卡片边框、圆角；不改变其他视图的留白。
- 终端标签采用普通界面字体 **12px**，不使用正文等宽字体。标签高 **28px**，左右内边距 **10px**、内部间隔 **6px**、标签间隔 **3px**、圆角 **6px**。
- 当前标签轻底色＋细边界，不加下划线；未选中标签无框、文字弱化。选中用 `aria-selected`，不只依赖颜色。
- 关闭符当前标签常显；其他标签鼠标悬停或键盘焦点进入时显示，保留占位避免宽度跳变。手机从菜单结束当前终端。
- ＋紧跟标签，低频重连／读屏／状态／快捷键／结束收进更多菜单。只让标签区域局部横向滚动，不挤掉全局操作。
- 桌面正文等宽字体 **14px**、约 **17px** 行高；不增加命令和输出的额外行距。真实 xterm 行高须用实际浏览器核查，不能以 HTML 稿的行高代替验证。
- 深色沿用石板灰；浅色沿用轻灰白。控件、xterm 背景、光标、选区、滚动条和 ANSI 色板同步适配主题，主题切换不重建 Shell。
- 手机仅显示当前终端下拉、新建与更多，工作区和终端列表进入下拉；保留全局设置入口，不挤成两行。

## 实现前必须核清的运行层边界

当前 `server/internal/projecttools/terminal.go` 限制每工作区一个运行终端；`agent.AcquireToolLease` 的持久归属、OS 锁和进程生命周期也不是现成的多 Shell 共享模型。**不能只删除数量检查，也不能让多个进程复用一个只记录单进程身份的租约。**

多终端需要补齐工作区终端组的进程归属、逐个结束、最后成员退出释放、崩溃与后代进程处理，以及与 AI／合并的整体互斥设计和红绿测试。没有核清前不放开限制，不把只读标签原型称为多终端实现。人工终端也不是系统沙箱。

自动接回需区分正常的首次进入与断网恢复；启动请求送达未知时先查询，不反复自动新建。仅保存无敏感信息的选择状态，不向浏览器存访问令牌、终端输入或输出历史。

## 已落地的运行层方案（2026-11-01）

- 每个人工工作区持有一个终端组及根工作区租约，沿用原 AI／文件写入／合并互斥；不是将多 Shell 塞入旧的单进程 marker。
- 每个成员有独立随机身份、启动窗和进程组。组 marker 持久化全部成员，未确认 PID 记录为0；未知或仍有活进程一律不放行。进程及普通后代继承根锁 FD，保持原 bash 禁用 job control／进程组回收边界，不承诺系统沙箱或任意主动逃逸程序隔离。
- 逐个结束只回收相应进程组；确认最后成员不存在后才清理根 marker、释放工作区。异常归属保留锁，不按持久 PID 向未知进程发信号。
- 服务器内串行处理首次 ensure；显式新建有 operationId，未知送达先查询。操作身份独立于32条结束历史，ensure 接回别名同样幂等；4096条记录上限拒绝额外操作，不靠淘汰旧身份再次启动。全局运行终端上限仍为8。
- 浏览器只保存项目视图、工作区／终端ID、手动关闭状态及待核查创建操作ID；不保存输入、输出或访问令牌。完成首帧回放前不启用输入，迟到范围回执不覆盖当前选择。未知送达不自动重发，显式操作可沿用同一操作ID核查／接回。
- 恢复前提仍为服务持续运行；服务重启或已手动结束时不偷偷另建 Shell，需要新的打开意图。
