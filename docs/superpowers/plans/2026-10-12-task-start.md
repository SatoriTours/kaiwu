# 任务开始开发实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 卡片按钮和聊天指令可靠启动原 pi 会话在独立工作区开发。

**Architecture:** Go workbench 保存幂等启动命令和执行记录；agent 在服务生命周期内准备 worktree、切换同一会话的工具与 cwd 并消费结果；Vue 两入口共享命令。Linux 执行进程组受服务管理，其他平台暂只读。

**Tech Stack:** 现有 Go／SQLite／pirpc、Vue／TypeScript／Vite，不增加后端语言或依赖。

**Spec:** [已确认方案](../specs/2026-10-12-task-start-design.md)。用户批准“按这个方案开发”，本计划细化同一授权，当前 Agent 串行实施并进行一次独立只读审查。不提交／推送，不调用真实模型。当前 unborn 仓库无隔离基线，按用户要求在本目录串行修改。

## Review Focus

检查旧进程／消费协程切换是否污染新执行；PID／进程组回收是否可能误杀；已保存回执但未调度是否可恢复且不重发；工作区身份／复制文件／符号链接边界；无配置／容量拒绝是否错误显示运行；CLI 接受和 settled 不同顺序是否伪造完成；只读模式是否被无意升级；非 Linux 是否误开放执行。
