## 实现

- `public/theme-init.js` 在页面 head 中以同源外部阻塞脚本加载，应用保存的合法偏好后再加载应用；不增加 inline script 或放宽 `script-src 'self'`。
- `ThemePicker.vue` 复用既有键盘可用的 `CustomSelect`，在顶栏与登录页使用图标入口。`kaiwu.theme` 仅记录 light/dark，选回系统删除覆盖；跨标签 storage 更新同步，组件卸载移除监听。
- 默认系统模式通过 CSS `prefers-color-scheme` 实时生效，无轮询、后台计时器或重载。读取／写入存储失败时仍可使用当前标签页的手动选择，刷新回到系统模式。
- `theme.css` 集中定义暗色语义色；原有浅色色值保留为 CSS 变量 fallback，仅将样式中的背景／文字／边框等接入主题。不改布局尺寸、组件业务或后端；纯白按钮文字与已有深底品牌按钮保持原配对。
- 静态资源仍由既有 Go 同源托管；新增 JavaScript 是 Web 客户端引导，不是自有后端／pi 宿主或扩展。
