# 顶栏项目菜单优化与验证

日期：2026-10-17。用户确认轻量项目菜单示意，并要求把项目 Git 操作归入项目菜单、全局操作靠右，保持美观且方便使用。本批是已有界面的限定调整，不新增后端接口、依赖或模型调用。

## 实际改动

- `apps/web/src/ProjectMenu.vue`：文件夹图标、当前项目名称与箭头组成轻量触发器；白色浮层展示项目、当前选中勾、Git 设置、刷新 Git 状态和添加项目。无项目时仍可直接添加。
- `apps/web/src/App.vue`、`style.css`：去掉原生项目下拉与散落的齿轮／刷新／添加按钮；默认模型、连接状态、退出组成右侧全局操作组。保留约 48px 顶栏。
- 沿用原项目切换、添加、Git 设置和只读刷新逻辑。点当前项目不退出已选任务、不清空草稿；真正切换项目时仍按各会话保存草稿。
- 支持方向键、Home／End、Enter／Space、Esc、Tab／Shift+Tab，选中状态与展开状态有 ARIA 标记。点击外部、焦点离开或组件卸载时正确关闭／清理监听。
- 长名称在顶栏省略、菜单内换行；项目列表独立滚动，手机菜单操作行增高，菜单限制在视口内。桌面／手机实际服务截图（合成测试项目）：[桌面](../design/web-service/project-menu-desktop.png)、[手机](../design/web-service/project-menu-mobile.png)。此前生成的 `project-switcher-proposal.png` 仅为设计示意，不是运行截图。
