# 回复语言修正与结果预览设计记录

日期：2026-10-16。

## 回复语言：实际实现及上线

用户要求回复统一使用系统语言。当前 Web 的 `lang="zh-CN"` 且界面为固定简体中文；pi 的原有启动提示只有访问范围和报告格式，没有回复语言约束。

在 `server/internal/agent/launch.go` 的统一 `--append-system-prompt` 中补充简体中文要求，覆盖正文、过程更新、问题、阻塞、最终摘要和结构化报告的自然语言字段。项目只读对话、任务只读讨论、切入开发工作区及原会话恢复均复用该入口。保留原工具输出、代码、路径、产品名、JSON 字段名、枚举及工具 ID；不改写已保存的英文历史，不增加模型调用。

实际运行：

- `GOCACHE=/tmp/kaiwu-go-cache GOTOOLCHAIN=local go -C server test ./internal/agent ./internal/workbench`：通过，分别 16.506s／10.476s。使用隔离假 pi，包含会话隔离、原会话切换开发／恢复及存储回归。
- `GOCACHE=/tmp/kaiwu-go-cache GOTOOLCHAIN=local go -C server build -o bin/kaiwu-server-reply-language ./cmd/kaiwu-server`：通过。
- 普通沙箱执行先因 Go 缓存只读／依赖缺失而无法启动；放宽执行权限后完成上述验证。没有新增依赖或修改模块文件。
- 上线前核对实际 7331 监听者是原 `kaiwu-server-auto-reconnect`，数据库两个会话均为空闲。优雅停止后使用原环境、原 cwd、原数据和端口启动新二进制；`/healthz` 返回 200。
- 更新前后只读核对：1 个项目、1 个任务、8 条消息、19 条登录记录，数量一致。PID 记录已更新。下一条新消息按现有自动接回规则加载新系统提示，不重放旧指令。

范围限制：这是系统提示约束及已有协议回归，**未发送真实模型请求验证其输出**，未重新执行全部 Go／race／浏览器服务回归，也不代表未来多语言切换已实现。没有提交、合并或推送 Git。

## 结果预览：当时仅设计（后续已实现）

用户反馈“确认结果”后不清楚系统做了什么，希望先预览效果。核对现有实现：`ProgressCard.vue` 发出确认事件，`App.vue` 调用 `confirm_result` 标记最新结果确认；没有实际效果预览能力。

已准备[设计方案](../superpowers/specs/2026-10-16-task-result-preview-design.md)和[可点击原型](../design/task-result-preview.html)：先查看效果／运行结果，再确认完成；完成反馈持续保留并提供后续合并入口。桌面效果在主内容区、任务对话仍在右侧，手机提供独立效果视图及返回入口。

实际用本机 Chromium 检查原型，16 项断言通过：效果入口、模拟接口输出、确认后的标题与卡片状态、后续入口、确认后效果保留、修改输入聚焦、预览失败／重试、CLI 输出、缺少效果、手机打开／返回、390px 无横向溢出及无页面脚本异常。截图：[桌面](../design/task-result-preview-desktop.png)、[手机](../design/task-result-preview-mobile.png)。

原型全部使用固定模拟数据，未启动真实任务预览、未操作 Git、未调用模型。**正式 Web 确认流程未修改，预览后端尚未实现**；方案等待用户评审。

## 2026-10-17 后续修正

原启动约束仍保留。现在每次用户明确发送时，RPC prompt 同时附上简体中文、Markdown 短段落／列表和完整可点击 URL 的输出要求，避免常驻／恢复会话继续沿用英文历史。原用户消息与会话身份保持不变，不自动调用模型翻译旧历史。隔离进程回归实际捕获首次、常驻第二轮、原身份恢复后三次请求，核对要求随每次请求送达、只有三次明确请求且历史原文不变；这证明协议送达，不代表已用真实模型验证遵循程度。最终联动验证见 [任务预览及聊天验证记录](web-task-result-preview-verification.md)。
