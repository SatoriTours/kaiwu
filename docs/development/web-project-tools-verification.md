## 安全边界

使用 Go os.Root 约束项目相对路径，拒绝目录穿越、绝对路径、Git 内部目录、符号链接和非普通文件；文件上传 O_EXCL，错误移除本次未完成文件。所有端点复用登录／同源验证，终端输入逐次验证登录，输出连接定期验证。

单附件 8 MiB、单消息 8 项／24 MiB；服务附件存储上限 1024 项／256 MiB，达到上限失败关闭，旧数据不自动删除。未发送附件也占配额；当前不提供自动回收或历史清理。内联仅 PNG／JPEG／GIF／WebP，其他文件强制下载；预览不执行 HTML／SVG。终端只传允许的基础环境变量，不导出服务令牌或 GitHub 凭据变量；服务器账号本身的权限不变。
