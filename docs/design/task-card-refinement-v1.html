01 / 减少容器，保持亮度

取消专题的大块实底，让卡片成为唯一内容表面。7px 圆角、1px 弱边框、无常驻阴影。选中轮廓只表示当前任务，不表示完成。

02 / 状态不铺满整张卡

执行中用小蓝点，待处理和待验收用琥珀色，失败用红色。始终有文字，不靠颜色猜。未开始不画状态底框。

03 / 有信息才增加一行

Git 与编号放在同一条轻量底栏，不为一个“待提交”多撑一行。子 Agent、待回答和交付信息才按需展开，长内容自然换行。
