# pi 外部接入说明

用户已明确自有后端全部使用 Go，本目录不再作为 TypeScript 扩展入口，不新增其他语言宿主；当前仅说明，尚无接入配置或联调成果。

Go 的 RPC 进程适配拟放 `server/internal/pirpc/`。本目录仅保留第三方 pi 的外部协议、受控启动配置和接入边界说明；实际 Go 代码归属 `server/`，不另建语言工程。

后续主 Agent 的派发、查询和结果回收优先研究 Go MCP 服务与 pi 内置 MCP 的对接，具体权限和工具路由另行设计；本批次不实现 MCP，也不声称已接管 pi 原生工具权限。

Go 拥有任务和生命周期，不能只用提示词模拟编排。测试优先使用 Go 隔离假进程，不继承个人扩展，不擅自启动真实 pi 或调用模型。
